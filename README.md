# 匕首世界

一座为私人跑团制作的虚构 MMO 官网，内含角色库和团员共用的冒险记录。

[进入匕首世界](https://jeffdyuyi.github.io/daggerworld-site/)

## 为什么做这个项目

作为主持人，我想让玩家从收到内测邀请码那一刻就开始进入游戏。打开一个像旧网游官网的页面，翻翻公告和版本档案，再激活账号、创建角色。开团以后，大家还能在同一个地方查角色、分配升级点和整理线索。

这个项目服务于我的桌游团和它的战役框架。站内公告、版本历史和测试入口属于虚构游戏设定。玩家侧以 MMO 客户端的口吻呈现，主持人则通过独立工坊管理规则资源和发放。站点是个人非商业项目，与《匕首之心》官方无隶属关系。

## 现在可以做什么

- 浏览复古 MMO 门户的新闻、指南、版本档案和资料片预告。
- 用邀请码进入角色库，创建及保存角色，管理装备、领域卡与升级。本站采用本团的 20 级累计经验和位阶规则。
- 主持人向角色发放经验、装备、领域卡和特殊效果。
- 团员共同维护冒险笔记、NPC 记录与线索墙。可把已有记录放入 Excalidraw 画布并查看正文，画布以共享云端版本保存。

## 项目技术

| 部分 | 实现 |
| --- | --- |
| 官网与角色编辑器 | HTML、CSS 和原生 JavaScript ES 模块。角色卡规则计算集中在 `editor/stats.js` 和 `editor/sheet-rules.js`。 |
| 账号和云端数据 | Supabase Auth、PostgreSQL、PostgREST 与行级安全策略。角色档案按账号访问，冒险记录按团成员权限共享。资源发放和升级条件由数据库校验，角色存档通过时间戳检查并发更新。 |
| 共享线索画布 | React 与 Excalidraw，由 Vite 单独构建。画布场景保存在 Supabase，保存时按修订号检测冲突。 |
| 构建和发布 | GitHub Actions 构建及打包站点，再部署到 GitHub Pages。发布前检查打包后的角色编辑器模块能否载入。 |

构建线索画布可运行 `npm ci` 和 `npm run build:adventure`。输出目录为 `dist/adventure-canvas`。发布工作流负责打包静态页面、编辑器、画布和字体资源。账号与云端功能需要相应的 Supabase 环境。

## 规则与素材

角色规则以 [《匕首之心》中文 SRD](https://daggerheart.cn/SRD/) 和本站采用的战役裁定为依据。中文规则、原始战役素材、美术和字体的署名与许可见站内制作名单及对应素材文件。第三方素材适用各自许可。
